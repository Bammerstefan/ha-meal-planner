# Mein Speiseplan v1.0.17 – Lizenzprüfung

Diese Version übernimmt die korrigierte Lizenzstatus-Rückmeldung aus dem vorherigen v1.0.16-Fix und aktualisiert die Versionsanzeige auf 1.0.17 (Manifest, Python-Backend, Benutzeroberfläche).

## Installation

1. Home-Assistant-Konfiguration sichern.
2. Den Inhalt von `custom_components/meal_planner/` über die vorhandene Integration kopieren.
3. Home Assistant neu starten und die Oberfläche neu laden (gegebenenfalls Cache leeren).
4. Unter Einstellungen > Zusatzmodule & Dauerlizenzen auf „Jetzt online prüfen“ klicken.

Dies ist ein Testupdate. Die tatsächliche Verbindung zum BamLabs-Server muss in deiner Installation geprüft werden.
